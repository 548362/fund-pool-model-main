# 基金多因子选基实验报告

## 1. 项目目标

本实验用于检验基金多因子评分是否能够预测下一期基金收益，而不是直接寻找一组样本内收益最高的参数。实验回答四个问题：

1. 哪些因子具有预测能力？
2. 哪些因子包含重复信息？
3. 改变评分组合后，策略表现是否改善？
4. 结果在不同时间段、交易成本和换手率下是否仍然成立？

## 2. 基金池与回测设置

基金池使用 `data/universe_v2_pool_seltype_main/universe_fund_v2_equity.csv`，共 50 只权益类基金。筛选原则是保留股票型和偏股混合型基金，排除债券、FOF、QDII、ETF 联接及持有期产品，并对同一底层基金的 A/B/C 份额去重，同时检查历史净值长度和覆盖率。

| 参数 | 设置 |
|---|---|
| 基金池 | 50 只权益基金 |
| 选基数量 | Top-10 |
| 权重方式 | 等权 |
| 调仓频率 | 月度 |
| 单边交易成本 | 10 bps |
| 请求区间 | 2022-01-01 至 2026-08-21 |
| 实际有效区间 | 2023-02-01 至 2026-08-21 |
| 基准 | 基金池每日等权组合 |

实际有效区间从 2023-02-01 开始，是因为因子计算严格要求 252 个实际交易日观测。四套方案之间只改变 `factor_weights`，其他参数完全相同。收益优先采用数据源日增长率，其次累计净值，最后回退单位净值。

## 3. 六个因子

| 因子 | 含义 | 评分方向 |
|---|---|---|
| `ann_return` | 滚动窗口年化收益率 | 越高越好 |
| `ann_vol` | 年化波动率 | 越低越好 |
| `down_vol` | 仅统计下跌日的下行波动率 | 越低越好 |
| `mdd` | 窗口内最大回撤，数值为负数 | 越接近 0 越好 |
| `sharpe` | 年化收益与年化波动率之比 | 越高越好 |
| `ir` | 基金相对基金池等权基准的风险调整超额收益 | 越高越好 |

每个调仓日只使用该日及之前的数据。因子先进行缩尾和稳健标准化，再按权重合成评分。由于 `mdd` 是负数，较小的回撤对应更大的数值，因此使用正权重。

## 4. 因子相关性

结果文件：

- `output/v2_factor_optimization/factor_correlation_by_rebalance.csv`
- `output/v2_factor_optimization/factor_correlation_mean.csv`

各调仓日横截面 Spearman 相关性的平均值如下：

| 因子对 | 平均相关性 | 解释 |
|---|---:|---|
| `ann_return` - `ir` | 0.972 | 信息高度重复 |
| `sharpe` - `ir` | 0.922 | 信息高度重复 |
| `ann_return` - `sharpe` | 0.919 | 信息高度重复 |
| `ann_vol` - `down_vol` | 0.904 | 信息高度重复 |
| `ann_vol` - `mdd` | -0.704 | 风险维度明显相关 |
| `down_vol` - `mdd` | -0.665 | 风险维度明显相关 |

结论：收益、Sharpe 和 IR 不是三个完全独立的信号；波动率和下行波动率也有明显重复。不能仅因为因子数量多，就认为评分信息更加丰富。

## 5. 因子分组收益

结果文件：

- `output/v2_factor_optimization/factor_group_returns.csv`
- `output/v2_factor_optimization/factor_group_summary.csv`
- `output/v2_factor_optimization/factor_spread_summary.csv`

每个调仓日按因子从低到高分为五组，持有至下一次调仓，比较最高组和最低组的下一期收益。

| 因子 | 高低组平均收益差 | 高组跑赢低组比例 |
|---|---:|---:|
| `ir` | +0.487% | 62.79% |
| `ann_return` | +0.395% | 58.14% |
| `sharpe` | +0.282% | 53.49% |
| `ann_vol` | -0.658% | 53.49% |
| `down_vol` | -0.966% | 51.16% |
| `mdd` | -0.886% | 48.84% |

结论：IR 和年化收益存在弱正向证据，但差异不大；风险因子作为收益排序变量时没有显示出稳定正向能力。综合原始六因子评分的高低组差异接近于零。

## 6. 四套评分方案

| 方案 | 因子权重 | 经济含义 |
|---|---|---|
| `baseline_corrected` | 收益、风险、Sharpe、IR 综合 | 修正后的原始基线 |
| `return_ir` | `ann_return` 0.40，`ir` 0.60 | 强调绝对收益和相对基准能力 |
| `sharpe_ir` | `sharpe` 0.50，`ir` 0.50 | 强调风险调整收益和相对收益 |
| `return_sharpe_ir` | `ann_return` 0.40，`sharpe` 0.30，`ir` 0.30 | 同时兼顾三类收益信号 |

完整区间结果：

| 方案 | 策略净收益 | 策略 CAGR | 策略 Sharpe | 最大回撤 | 基准收益 | 超额收益 | 年化换手率 | 是否跑赢 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| `baseline_corrected` | 15.63% | 4.18% | 0.307 | -28.18% | 20.91% | -5.27% | 3.07x | 否 |
| `return_ir` | 20.43% | 5.37% | 0.346 | -32.12% | 20.91% | -0.48% | 2.99x | 否 |
| `sharpe_ir` | 17.84% | 4.73% | 0.325 | -32.73% | 20.91% | -3.07% | 3.21x | 否 |
| `return_sharpe_ir` | 16.89% | 4.49% | 0.310 | -34.95% | 20.91% | -4.01% | 3.10x | 否 |

## 7. 交易成本与换手率

交易成本按调仓时交易金额乘以 10 bps 计算，并从策略净收益中扣除。四套方案的累计理论交易成本约为 2.30% 至 2.44%，年化换手率约为 2.98 至 3.16 倍。

`return_ir` 是四套方案中最接近基准的一套，但完整区间仍略微跑输，且最大回撤和波动高于基准。因子分组的正向差异没有稳定转化为扣费后的组合超额。

## 8. 分阶段稳定性

结果文件：`output/v2_factor_optimization/score_scheme_period_summary.csv`。

前半段为 2023-02-01 至 2024-12-31，后半段为 2025-01-01 至 2026-08-21。

`return_ir` 的表现：

| 时段 | 策略收益 | 基准收益 | 超额收益 | 是否跑赢 |
|---|---:|---:|---:|---|
| 前半段 | -19.03% | -15.14% | -3.89% | 否 |
| 后半段 | +48.73% | +42.47% | +6.26% | 是 |

这说明完整区间的正超额主要来自后半段，尚未表现出跨市场阶段稳定有效的特征。

## 9. 局限性

1. 样本只有 50 只基金，且基金池覆盖范围有限。
2. 回测区间有限，结论可能受特定市场阶段影响。
3. 收益、Sharpe 和 IR 之间高度相关，独立有效因子数量较少。
4. 尚未完整建模申购赎回费、滑点和实际成交价格。
5. 基金净值是日频数据，无法完全模拟盘中交易和真实调仓时点。
6. 本实验进行了历史分段比较，但还不能替代更长时间的样本外验证。

## 10. 最终结论

在固定基金池、Top-10、等权、月度调仓和 10 bps 交易成本的条件下，四套评分方案完整区间均未跑赢基金池等权基准。`return_ir` 最接近基准，但前半段跑输、后半段跑赢，且最大回撤更大。因此，当前证据不支持 IR + 收益方案具有稳定长期超额。

本项目的主要成果不是找到一套确定盈利的策略，而是建立了一个包含基金池筛选、点时因子计算、因子诊断、滚动回测、基准比较、交易成本和分阶段稳定性检验的研究框架，并据此得出谨慎、可复现的结论。

## 11. 复现实验

```powershell
python run_score_scheme_experiments.py `
  --universe data/universe_v2_pool_seltype_main/universe_fund_v2_equity.csv `
  --start 2022-01-01 `
  --end 2026-08-21 `

```

该命令使用仓库当前实际存在的方案 B 基金池路径。

## 12. 从代码到结果的对应关系

本报告中的结果不是手工整理的静态数字，而是由以下代码链路生成：

| 研究环节 | 代码 | 主要输出 |
|---|---|---|
| 因子计算 | `src/domain/factors.py` | 六个横截面因子 |
| 因子标准化和评分 | `src/domain/scoring.py` | `score`、`rank` |
| 单因子分组诊断 | `src/backtest/factor_diagnostics.py` | `factor_group_*.csv` |
| 评分方案配置 | `src/backtest/score_schemes.py` | 四套权重 |
| 批量滚动回测 | `run_score_scheme_experiments.py` | 各方案滚动结果 |
| 回测会计 | `src/backtest/accounting.py` | 换手和交易成本 |
| 绩效指标 | `src/backtest/metrics.py` | CAGR、Sharpe、最大回撤等 |

每套评分方案都写入独立目录，避免覆盖其他方案或此前的 `output/v2_equity_pool`、`output/v2_sensitivity` 结果。

## 13. 因子计算口径补充

当前 `compute_factors()` 使用最近 `window_days` 条日收益，默认窗口为 252 个交易日：

- `ann_return = 日平均收益率 × 252`；
- `ann_vol = 日收益标准差 × sqrt(252)`；
- `down_vol` 为负收益样本标准差再年化；
- `sharpe = 日平均收益率 / 日波动率 × sqrt(252)`；
- `ir = 超额收益平均值 / 跟踪误差 × sqrt(252)`；
- `mdd` 为 `(1 + 日收益).cumprod()` 相对历史峰值的最小回撤。

因此这里的 `ann_return` 是基于日均收益的年化指标，不是严格的几何复合年化收益；策略净值的 CAGR 则使用实际净值曲线的复合收益计算。两者不能混为同一个指标。

## 14. 研究结果的使用边界

`return_ir` 的完整区间落后基准约 0.48 个百分点，而且前半段跑输、后半段跑赢。这个结果适合说明“如何通过因子诊断提出并否证过强假设”，不适合在简历或报告中表述为已经获得稳定超额收益。正式结论应同时保留等权基准、交易成本、最大回撤、存活偏差和分阶段结果。
